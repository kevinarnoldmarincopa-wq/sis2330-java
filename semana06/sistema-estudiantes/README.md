# Sistema de Estudiantes

Proyecto desarrollado para la Semana 06 de SIS2330.

## Descripción
Sistema de gestión de estudiantes desarrollado en Java utilizando Maven.

## Funcionalidades
- Registrar estudiantes.
- Buscar estudiantes por código.
- Actualizar promedios.
- Eliminar estudiantes.
- Mostrar ranking de estudiantes.
- Consultar los mejores estudiantes.

## Tecnologías
- Java 17
- Maven
- JUnit 5

## Ejecutar el proyecto
```bash
mvn package
java -cp target/classes Principal
