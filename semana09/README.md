# Semana 09 - Vaadin Router y Vistas

## Objetivo
Implementar navegación entre diferentes vistas utilizando Vaadin.

## Funcionalidades
- Menú lateral con AppLayout.
- Lista de tareas utilizando Grid.
- Agregar nuevas tareas.
- Consultar detalles mediante el ID.
- Vista Acerca de.
- Navegación mediante RouterLink.

## Clases principales
- MainLayout
- TareasView
- TareaDetalleView
- AcercaDeView
- Tarea

## Ejecución
Ingresar a la carpeta app y ejecutar:

mvn spring-boot:run

Abrir en el navegador:

http://localhost:8080
