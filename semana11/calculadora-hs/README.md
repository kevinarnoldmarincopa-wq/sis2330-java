# Semana 11: Haskell I - Entorno, Tipos y Pureza

## Descripcion

Calculadora sencilla desarrollada en Haskell.
Permite ingresar dos numeros y mostrar su suma.
Tambien contiene funciones puras para calcular el doble y el promedio.

## Como correr

Ejecutar los comandos:

stack build
stack run

## Modulos

- Lib.hs: contiene las funciones puras suma, doble y promedio.
- Main.hs: contiene el programa principal y permite ingresar dos numeros por consola.
