# Semana 3 - POO I

## Objetivo
Aplicar Programación Orientada a Objetos mediante clases, objetos, constructores y encapsulación.

## Contenidos
- Clases y objetos.
- Atributos y métodos.
- Constructores y `this`.
- Encapsulación con `private`, getters y setters.
- `ArrayList<T>`.
- Paquetes `modelo` y `app`.

## Proyecto: Gestor de Tareas
- Agregar tareas.
- Listar tareas.
- Marcar tareas completadas por ID.
- Eliminar tareas por ID.
- Menú de consola.
- Validación de entrada con Scanner e InputMismatchException.

## Tecnologías
- Java.
- Termux.
- Git.
- GitHub.
