
# Semana 2 - Fundamentos de Java

## Objetivo
Practicar los fundamentos de Java mediante variables, operadores,
condicionales, ciclos, arreglos, métodos y entrada de datos.

## Contenidos
- Tipos de datos primitivos.
- Operadores aritméticos.
- Condicionales if-else.
- Ciclos for y while.
- Arreglos unidimensionales.
- Arreglos bidimensionales.
- Métodos static.
- Scanner.
- InputMismatchException.

## Proyecto: Sistema de Calificaciones

El programa registra 5 estudiantes y 3 notas por estudiante.

Funciones:
- Calcular promedio.
- Obtener nota máxima.
- Obtener nota mínima.
- Determinar aprobado o reprobado.
- Mostrar reporte final.
- Validar notas entre 0 y 100.
- Manejar entradas incorrectas.

## Tecnologías
- Java 21 en Termux.
- Git.
- GitHub.
