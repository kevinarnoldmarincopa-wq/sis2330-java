# Semana 07 - Vaadin Fundamentals

## Descripción
Aplicación web de gestión de tareas desarrollada con Java, Spring Boot y Vaadin.

## Funcionalidades
- Campo para ingresar la descripción de una tarea.
- Botón Agregar para registrar tareas.
- Visualización de tareas en pantalla.
- Limpieza automática del campo después de agregar.
- Notificación cuando se intenta agregar una tarea vacía.

## Tecnologías
- Java 21
- Spring Boot 3.4.5
- Vaadin 24.7.10
- Maven

## Ejecución
Desde la carpeta app:

```bash
mvn spring-boot:run
