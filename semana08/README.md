# Semana 8 - Vaadin Grid, Binder y CRUD

## Objetivo
Ampliar el gestor de tareas utilizando Vaadin Grid y Binder.

## Funcionalidades
- Registrar tareas.
- Mostrar tareas en una tabla.
- Editar tareas seleccionadas.
- Eliminar tareas.
- Marcar tareas como completadas.
- Validar la descripción mediante Binder.

## Tecnologías
- Java 21
- Spring Boot
- Vaadin
- Maven

## Ejecución
Ingresar a la carpeta app y ejecutar:

mvn spring-boot:run

Abrir en el navegador:

http://localhost:8080
