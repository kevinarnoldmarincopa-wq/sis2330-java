# Estadisticas de Estudiantes

## Descripcion
Programa desarrollado en Haskell para registrar estudiantes y calcular estadisticas de sus calificaciones.

## Funciones
- Registrar estudiantes y sus notas.
- Calcular el promedio de la clase.
- Identificar al estudiante con la nota mas alta.
- Ordenar estudiantes por calificacion.
- Mostrar estudiantes aprobados con nota mayor o igual a 51.
- Controlar cuando no existen estudiantes registrados.

## Conceptos utilizados
- Listas y tuplas.
- Funciones.
- Recursion.
- Pattern matching.
- mapM_ y filter.
- foldr.
