# Semana 10 - Vaadin, Spring Boot y Deploy

## Descripción
Sistema de gestión de tareas desarrollado con Java, Spring Boot y Vaadin.

## Funcionalidades
- Registrar tareas.
- Listar tareas.
- Editar tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Consultar el detalle de cada tarea.
- Guardar los datos en un archivo JSON.

## Tecnologías
- Java 21
- Spring Boot
- Vaadin
- Maven
- Gson

## Ejecución
Desde la carpeta app:

mvn spring-boot:run

## Generar archivo ejecutable
mvn clean package

Archivo generado:
target/app-1.0-SNAPSHOT.jar
